# Operator Console v2

Отдельное приложение оператора, которое взаимодействует с основным проектом только через HTTP API.

## Рабочие режимы

### SEARCH

- отображает обнаружения движения красными рамками;
- не показывает список целей и подробные данные;
- одна цель выбирается одним щелчком по рамке;
- правая панель содержит состояние детектора и базовое управление.

### TRACKING

- активная цель отображается зелёной рамкой;
- одновременно сопровождается только одна цель;
- правая панель автоматически переключается на данные активной цели;
- верхняя лента постепенно показывает результаты автоматического обогащения;
- кнопка «Прекратить сопровождение» возвращает консоль в SEARCH.

## Архитектурные заготовки

- `public/js/target-registry.js` — локальный контракт будущего `TargetRegistry`;
- `public/js/intelligence-coordinator.js` — единая точка запуска AI, Radar, AIS, ГАБ и других источников;
- состояния источников: `pending`, `ready`, `not_found`, `stale`, `error`.

В текущей версии внешние источники имитируются безопасными заглушками. Реальные запросы ещё не выполняются.

## Запуск

```powershell
node .\src\tools\operator-console\server\server.js
```

Открыть:

```text
http://127.0.0.1:8090
```

Устанавливать npm-пакеты не требуется.

## Ограничение

Видеопоток пока не подключён. Canvas отображает координатную сетку и реальные рамки из Tracking API.
