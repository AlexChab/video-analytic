# Tracking Operator Console

Отдельное приложение для проверки HTTP API ручного сопровождения. Консоль не импортирует классы основного проекта и взаимодействует с ним только по HTTP.

## Возможности версии 0.3

- получение `/api/tracking/objects` и `/api/tracking/status`;
- выбор цели по координате или ID;
- команды `reset`, `enable`, `disable`;
- Canvas с пересчётом координат исходного кадра;
- визуализация рамок объектов;
- автообновление данных;
- компактная постоянно видимая диагностика;
- нижняя диагностическая панель с вкладками `Status JSON`, `Objects JSON`, `Last response`, `Журнал запросов`;
- один общий скролл внутри активной нижней вкладки вместо нескольких вложенных полос прокрутки;
- копирование JSON и очистка журнала;
- локальный proxy без изменения CORS основного приложения.

## Установка

Замените существующий каталог:

```text
src/tools/operator-console
```

каталогом `operator-console` из архива.

## Запуск

```powershell
node .\src\tools\operator-console\server\server.js
```

Откройте:

```text
http://127.0.0.1:8090
```

Устанавливать npm-пакеты не требуется.

## Ограничение текущей версии

Видеопоток намеренно не подключён. Canvas использует координатную сетку и реальные рамки из Tracking API.
